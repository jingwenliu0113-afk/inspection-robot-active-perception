## C6 的細節：定位誤差讓「看穿」變得不安全

- 用**真實**相機位姿時，每個物件存在的視角至少有 3 個位置（消防栓本身）看不穿——v2 的安全性質成立。
- 用 **AMCL 估計**位姿時，機載 depth 與幾何的中位誤差是 2.6 cm（p95 5.0 cm），已經接近 / 超過 v2 的 3 cm 看穿容忍值：
  - 1 個單一視角（`g0000-v0` 目標 0）64 個位置全部被算成看穿；
  - **所有視角聯集**時，6 個物件存在的 episode 中有 **2 個**（`g0000-v0`、`g0005-v0`）全部被算成看穿（真實位姿下是 95.3%、93.8%）——
    不同視角的位姿誤差方向不同，各自「吃掉」不同的保護位置，聯集後保護消失。
- 這些情況 detector 都有看到消防栓（判定仍是 `present`），所以 B0 沒有出現錯誤答案；但若 detector 漏看，v2 會回答 `absent`。
- 敏感度（從真實位姿刻意偏移，90 個物件存在的視角）：單一方向的誤差要到朝向 0.06 rad 或位移 8–10 cm 才會讓單一視角不安全；
  實際的位置加朝向的組合誤差，以及多視角聯集，在更小的誤差下就會出事。

判定：依 decision 015 §5，C6 未成立代表需要研究設計上的變更 → **不進 B1，詢問使用者**；不自行修改凍結的 v2。
