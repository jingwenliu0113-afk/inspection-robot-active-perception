# v5 depth 比例自我校正：開發紀錄（decision 033）

**這裡的數字全部來自開發資料**（評估 `v3-dev`，校正 `v3-dev-dx`），用來選擇元件與決定是否值得做正式測試，**不是正式結果**。
v4 的正式資料（`v4`、`v4-dx`）不用於 v5 的開發。凍結 v4 的對照數字是既有的 v4 開發輸出（`runs/v4-dev`，同資料、同誤差抽樣）。

## 1. 自我校正可行

校正只用部署時拿得到的東西：凍結 v4 在先前巡檢視角上的精修結果（機載 depth、定位器估計、設施地圖），取精修成功視角的擬合比例中位數；
另在每個停點靜止連拍兩張，以兩張 depth 的逐像素比例中位數估計逐張浮動。

| 誤差條件 | 真實比例 | 校正值（120 集） | 靜止重拍估得的浮動 | 真實浮動 |
|---|---|---|---|---|
| D0×P0 | 1.000 | 1.0000 | 0.0000 | 0 |
| D1×L1 | 1.010 | 1.0050 | 0.0000 | 0 |
| D2×L2 | 1.020 | 1.0150 | 0.0000 | 0 |
| D3×L1 | 0.975 | 0.9750 | 0.0106 | 0.010 |
| D3×P0 | 0.975 | 0.9750 | 0.0106 | 0.010 |
| D1×L2（回報 L1） | 1.010 | 1.0050 | 0.0000 | 0 |

- 單一視角的擬合比例很分散（MAD 1.5–2.2%，9–24% 卡在搜尋上緣 1.045），但中位數穩定。
- D1 / D2 少 0.5%：v4 的比例網格（假設 ±0.005 細化）到不了 1.01、1.03。平均數、去尾平均都沒有一致地更準。
- 需要的校正量：5–10 集時中位數在 0.970–0.980 之間跳動；只在初始視角重拍（每集 1 組）時浮動估計在 0.7–1.3%。
  約 40 集才穩定；重拍改為每個停點一組（每集 13 組，不增加精修計算）。

## 2. 只縮窄比例假設帶：位姿更準，但安全代理變差、absent 幾乎不變

假設帶 = 校正值 ± B，5 個假設，其餘與凍結 v4 相同（看穿判定仍用原始 depth）。

| 條件 | 設定 | 超出餘裕（其中精修成功） | 精修成功 / 不提供看穿 | Rule b2 / b3 / b5 | absent@5 |

| D1×L1 | v4 | 8 (4) | 936 / 93 | 0.775 / 0.925 / 0.992 | 0.983 |

所有列的 FA、FP、GR、全視角、佔用看穿都是 0。j2 在 D1 / D2 下等於 ±1%（浮動估計為 0）。

- **位姿更準**：D1×L1 精修成功的視角，±1% 帶的位置誤差中位 1.6 → 0.8 cm、p95 6.9 → 4.4 cm；假設離散度中位 3.3 → 2.1 cm；64 個原本不提供看穿的視角變成可用（反向 3 個）。
- **但超出餘裕增加**（±1%：D2×L2 11 → 17、D3×L1 5 → 9）。多出來的視角大多是**比例已擬合在真值附近、位置卻錯 7–14 cm** 的錯誤收斂，與比例無關（L2 的大定位誤差、2D 精修修不到的高度 / 俯仰誤差）。
  v4 能擋下它們，是因為遠離真值的比例假設（例如 0.955）恰好給出很不同的位姿，把離散度撐到 20 cm 以上。
  **v4 的寬假設帶有一部分保護是意外的多起點一致性檢查**，不只是在涵蓋比例。
- 降低成功時的基本餘裕（6 cm）也不可行：以每視角紀錄離線計算，D1×L1 ±1% 帶在 4 cm 時超出 13 個、5 cm 時 7 個（6 cm：5 個）。尾端誤差才是問題。
- 維持 v4 安全水準的帶寬（±2%、j2）在 D3×L1 下 absent 沒有改善（0.733 / 0.750 對 0.767）。

## 3. D3 的 absent 主要被看穿判定用的原始 depth 限制

- 同資料上，v3（固定 6 cm 餘裕、沒有比例假設）的 D3×L1 absent@5 也只有 0.817；D0×P0 與 D1×L1 是 1.000。
- D3 的 depth 平均短 2.5%：在 2–3 m 是 5–7.5 cm，超過 3 cm 的看穿容忍值，靠近地面的位置因此「看不穿」。這與位姿精修無關，縮窄假設帶救不回來。
- 候選（開發中新增，凍結前須寫進 decision）：**看穿判定改用 原始 depth / ŝ**。
  - 校正後的殘差是對稱的逐張浮動（D3 1% σ）加校正誤差（約 0.5%），往「看起來更遠」方向的偏差比 D2 一直 +2% 小；D2 在所有正式測試中都安全。
  - D1 / D2 的偏差為正，校正讓 depth 變短，是更安全的方向，但 absent 可能略降。
  - 安全仍以同一組指標檢驗（特別是佔用位置看穿）。
