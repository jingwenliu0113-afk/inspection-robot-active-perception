> r ≈ 1 只代表 depth 分辨不出，不代表定位器是對的（`v3-dev-dx` D1×L2 有 3 個 r ≤ 1.07 的視角定位器誤差 10–13 cm）。本診斷的數字不變。

## 結論先講

1. **D3×P0 的 absent 失敗不是「真正不可觀測」**。
   - 乾淨 depth、真實位姿下，60 個 absent 集用全部 13 個視角都能完全清除；Rule 原本選的 5 個視角也全部能清除（T0：60 / 60）。
   - D3 depth、真實位姿下，同樣的 5 個視角 59 / 60 能清除。
2. **14 個失敗全部是定位處理造成的**：Rule 選的 5 個視角中有 1–4 個被判「精修與定位器矛盾」而不提供看穿。同樣的 5 個視角若用真實位姿，14 集**全部**能清除。
3. **在 P0 下，被判矛盾的視角 100% 是精修錯、定位器對**：精修誤差 p50 4.9 cm、p95 14.8 cm，定位器誤差 0。
   原因是 P0 的定位器回報 1 cm 的不確定度，先驗閘門只有 3 cm；D3 depth 誤差讓精修本身偏移超過 3 cm，就被當成矛盾。
   定位器**越準**，被浪費的視角反而越多（D3×L1 只有 103 個，D3×P0 有 454 個）。
4. **有一個可部署的特徵能區分「精修錯」與「定位器錯」**：在定位器位姿上的擬合成本 ÷ 精修解的擬合成本。
   P0 的矛盾視角大多 ≤ 1.3；定位器真的錯（D1×L2 回報 L1）時，中位數約 33。

## 2. 視角層級：定位誤差與看穿

| 條件 | 精修成功 / 判矛盾而不提供看穿 / 退化（寬餘裕） | 判矛盾的視角：定位器誤差 p50 / p95 | 精修誤差 p50 / p95 | 定位器比精修準的比例 |
|---|---|---|---|---|
| D0×P0 | 973 / 0 / 587 | — | — | — |
| **D3×P0** | 558 / **454** / 548 | 0 / 0 cm | 4.9 / 14.8 cm | **100%** |
| D3×L1 | 908 / 103 / 549 | 4.6 / 8.8 cm | 9.2 / 20.1 cm | 79% |
| D1×L2（回報 L1） | 594 / 436 / 530 | 10.3 / 17.5 cm | 2.1 / 12.5 cm | 14% |

- 判矛盾的視角在真實位姿下原本能清除的位置，佔 v5 實際清除量的比例：D3×P0 **38%**、D1×L2 31%、D3×L1 7%、D0×P0 0%。
- 精修的移動大多沿著光軸（|cos| 中位 0.82）：這正是 depth 比例誤差與平移互相補償的方向（v4 開發紀錄）。
- **矛盾規則的兩面**：在 D1×L2（定位器過度自信）時，86% 的矛盾視角中精修比定位器準（其中 272 個定位器誤差超過寬餘裕），這時不提供看穿是對的，也是 v3 加入這條規則的原因。在 P0 時同一條規則把正確的定位器丟掉了。

## 3. 能否用可部署的資訊區分兩種矛盾

特徵：定位器位姿（允許比例假設）的擬合成本 ÷ 精修解的擬合成本。比值接近 1 表示 depth 無法分辨兩者；比值很大表示定位器位姿明顯解釋不了 depth。

| 條件（判矛盾的視角） | 比值 p50 / p95 | 定位器其實錯（誤差 > 寬餘裕） |
|---|---|---|
| D3×P0 | 1.18 / 1.69 | 0 / 454 |
| D3×L1 | 1.9 / 32 | 5 / 103 |
| D1×L2（回報 L1） | 20.5 / 213（定位器錯的 p50 32.8） | 272 / 436 |

若比值 ≤ c 時改用定位器位姿（離線估計，Rule 路徑固定，C1 用 max(6 cm, 3σ) 餘裕，略偏樂觀）：

| c | D3×P0：接受的視角 / 救回的失敗 | D3×L1 | D1×L2（回報 L1）：接受 / 其中定位器錯 | 被佔用位置被清除 |
|---|---|---|---|---|
| 1.2 | 254 / 11 of 14 | 13 / 2 of 3 | 0 / 0 | 0 |
| **1.3** | **331 / 12 of 14** | 21 / 2 of 3 | **1 / 0** | 0 |
| 1.5 | 401 / 13 of 14 | 34 / 3 of 3 | 3 / **1** | 0 |

c = 1.5 已經會接受一個定位器錯誤的視角，所以安全上限在 1.3 附近。

## 4. 限制

- 開發資料 120 集；D1×L2 的「定位器錯」視角 272 個，c ≤ 1.3 時 0 個被接受，但這是有限樣本，不是保證。
- 離線估計把 Rule 的路徑固定；實際上清除狀態改變後，Rule 會選不同的視角。
- C1 用 6 cm 的餘裕（P0）；候選規則打算用既有的失敗擬合餘裕 max(10 cm, 3σ)，清除會略少。
- 模擬中的定位誤差每個視角獨立；真實定位誤差在時間上相關。
- D3 的參數來自公開平面資料；立體遮蔽帶沒有實測。
