## 1. 凍結的 v3（`activeperception/v3/frozen_v3.py`）

不變的部分：

- `detector-v1`（FRCNN-MobileNetV3，COCO 預訓練，未微調）。
- `decision-v2` 的門檻：`tau_present` 0.7、`tau_absent` 0.02、`tau_clear` 1.0、`col_min` 1.0。
- 64 個位置、容忍值 0.03 m。
- `r0b_noise.py` 的誤差模型。

| 元件 | 凍結內容 |
|---|---|
| `decision-v3`（zone 過濾） | 以 depth 定位每個偵測框：取框中央一半的 depth 中位數，沿框中心射線投影。<br>位置在 zone 半徑 + 0.25 m 內才算「zone 內」。<br>中央一半的有效 depth < 30% 時算「無法定位」。<br>present 只看 zone 內偵測的最高信心；absent 會被 zone 內或無法定位的偵測擋下（保守）。 |
| `see-through-v3` | 每個軸點看 5×5 鄰域：有效像素 ≥ 40%，且**全部**有效像素都在軸點之後（扣掉容忍值）才算看穿。<br>缺值像素不算看穿，也不會單獨擋下。 |
| `nav-pose-v3` | 沿用 decision 016 的二維對齊，加上：<br>- 依距離加權：depth 誤差先驗取規格上限 2%@2 m、∝ z²；擬合誤差 0.02 m。<br>- 5 m 截斷。<br>- depth 比例搜尋：0.98 / 1.00 / 1.02，再細化 ±0.005。<br>- 退化檢查：最小特徵值 10。<br>- **定位器先驗閘門**：精修結果偏離估計位姿超過 3σ（σ 為定位器自己回報的共變異數）時，判精修失敗。 |
| `nav-margin-v3` | 精修成功：（待定）。<br>精修失敗：max(decision 016 的寬餘裕 0.10 m / 0.06 rad, 3σ)。 |
| `rule-nbv-v3` | （待定：開發結果確認平手處理是否保留）。 |

定位器回報的共變異數：模擬中取誤差模型的 σ，下限為 0.01 m / 0.005 rad。
這等於假設定位器**誠實回報**自己的不確定度。§3 的 M 條件專門檢查定位器過度自信時會發生什麼。

## 3. 條件與管線

管線：

- **v2**：decision 016（＝ R0b 管線 b），沒有 zone 過濾，`rule-nbv-v2`。
- **v3**：§1 的全部元件。

| 資料 | 條件 | 管線 |
|---|---|---|
| `v3` | D0×P0（乾淨） | v2、v3 |
| `v3` | **D1×L1（典型）** | v2、v3 |
| `v3` | D2×L2（壓力） | v2、v3 |
| `v3` | **M：D1×L2，但定位器回報 L1**（過度自信 2 倍） | v2、v3 |
| `v3-dx` | D0×P0、D1×L1 | v2、v3 |

- 四個方法（Single、Random seeds 0–2、Rule-NBV、Oracle）以 Core harness replay，budget 1–5。
- 誤差抽樣與 R0b 相同：每個 (episode, 視角, 等級) 一個固定串流，兩條管線成對比較。
- 共 12 個 job，**每個只跑一次**（`python -m activeperception.v3.formal`，`results/v3/` 已存在時拒絕重跑）。

## 4. 指標（定義與 R0b 相同，不放寬）

| 指標 | 定義 |
|---|---|
| false absent（FA） | 判 absent 但物件存在 |
| false present（FP） | 判 present 但物件不存在 |
| geometric risk（GR） | 物件存在、但所選視角的聯集把 64 個位置都看穿 |
| all-views GR | 物件存在、13 個視角全部聯集後 64 個位置都看穿 |
| 佔用位置看穿 | 物件中心 0.06 m 內的位置在某視角被判為看穿（逐視角計數） |

FA、FP、GR 都是四個方法 × budget 1–5 的總和。

## 5. 預先登錄的判準

| # | 判準 | 條件 | 通過條件 |
|---|---|---|---|
| **V1（主要：安全）** | v3、`v3` D1×L1 | FA 0、FP 0、GR 0、all-views GR 0、佔用位置看穿 0 |
| **V2（主要：absent 可判）** | v3、`v3` D1×L1 | Rule budget 5 的 absent 正確率 ≥ 0.90 |
| **V3（主要：zone 過濾）** | v3、`v3-dx` D0×P0 與 D1×L1 | 兩個條件都 FP 0，且滿足 V1 的其他安全條件 |
| V4（壓力） | v3、`v3` D2×L2 | 同 V1；報告通過或失敗 |
| V5（過度自信的定位器） | v3、`v3` M | 同 V1；報告通過或失敗 |
| V6（代價） | 所有條件 | 只報告：四個方法在 budget 2 / 3 / 5 的準確率、inconclusive rate、精修成功率、位姿誤差、v3 − v2 差異（成對 bootstrap，以 scene group 為單位） |

解讀（事先寫定）：

- V1–V3 全部通過，才可以說：「在模型化的典型 depth 雜訊與定位誤差下，v3 保持 v2 的安全性、讓 absent 重新可判，並排除 zone 外的相似物件。」
  這是**模擬**結論，不是真實感測器或實機結論。
- V1 未通過：v3 不得取代 v2；記錄失敗的元件。
- V2 未通過但 V1 通過：v3 安全但代價未改善；報告實際的 absent 正確率。
- V3 未通過：zone 過濾在模擬中也不足以排除 zone 外的相似物件；報告 FP 的來源。
- V4 / V5 未通過：記錄安全邊界的位置，不改變 V1–V3 的結論。
- 不論結果，R0a 發現的 **zone 內**相似物件（管件、閥門、柱狀設施）都不在 v3 處理範圍，列為限制。
