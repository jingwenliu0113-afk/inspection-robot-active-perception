# 034 — 凍結 v5，以及 v5 的正式測試協定

- **日期**：2026-10-16
- **狀態**：凍結。本檔 commit 之後才產生正式資料（`v5`、`v5-dx`），正式評測只跑一次。
- **是否在看過正式結果後才寫**：否。v5 沒有任何正式結果；選擇只根據開發資料（decision 033 與附錄 A、[docs/v5-development.md](../v5-development.md)）。

## 1. 凍結的 v5（`activeperception/v5/frozen_v5.py`）

**v5 = 凍結 v4（decision 031）＋ see-v5**。位姿精修、比例假設、餘裕、zone 過濾（`decision-v4`）、decision-v2 門檻、`detector-v1`、rule-nbv-v2 全部與 v4 相同。

| 元件 | 凍結值 |
|---|---|
| see-v5 | 27 個位姿各自判為 看穿 / 被擋 / 缺值（5×5 鄰域有效像素 < 40%）/ 畫面外。**任一位姿被擋或畫面外就否決**；至少 **k = 14** 個位姿看穿；每個缺值位姿的投影必須落在看穿位姿的投影之間（影像欄位，「包住」） |
| 比例自我校正 | **不採用**（開發中有得有失；看穿用校正 depth 沒有作用） |

- k = 27 時 see-v5 等於 v3 / v4 的規則（測試確認逐值相同）；沒有缺值的 depth 下 v5 與 v4 相同。
- 開發依據（`v3-dev` / `v3-dev-dx`，9 個資料 × 條件組合）：FA、FP、GR、全視角、佔用看穿全部 0；
  Rule budget 3：D2×L2 0.767 → 0.950、D3×L1 0.758 → 0.875；absent@5：D3×L1 0.767 → 0.950、D3×P0 0.633 → 0.767；成對比較 v4 對、v5 錯的集數最多 1。
- 「不包住」版本（k = 14，畫面外否決，缺值不需被包住）是只報告的消融：開發上收益更大（D3×L1 budget 2 0.725 → 0.925）但安全理由較弱（decision 033 附錄 A、開發紀錄 §4）。

## 4. 判準（事先寫定，不放寬）

「安全」＝ FA、FP、GR（策略所選視角）、全視角 GR、佔用位置看穿（0.06 m）全部為 0（decision 025 的 V1）。

| # | 判準 | 通過條件 |
|---|---|---|
| **X1（主要）** | v5 在全部 8 個條件 | 安全 |
| **X2（主要）** | v5 − v4 的 Rule budget 3 準確率（成對，scene group cluster bootstrap 95% CI），`v5` D2×L2 與 D3×L1 | 兩者的 CI 下界都 > 0 |
| **X3（主要）** | `v5` D0×P0 | v5 與 v4 的結果逐項相同（無缺值時規則相同） |
| X4 | 所有條件 × budget 2 / 3 / 5 的 v5 − v4 | 沒有任何一個 CI 上界 < 0（沒有顯著變差） |
| R1 | absent@5、各 budget 的 Rule 準確率、成對差異 | 只報告 |
| R2 | 不包住版本的安全與準確率 | 只報告 |

X2 的理由：D2×L2 與 D3×L1 是 v4 為了安全付出 absent 代價的條件（decision 032 §4），也是 v5 要改善的地方。

## 5. 解讀（事先寫定）

- X1–X3 通過：可以說「在模擬的典型、壓力與 D3 誤差下，see-v5 保持安全，並在 v4 付出代價的條件下提高 Rule 準確率」。仍然是**模擬**結論。
- X1 未通過：記錄機制；v5 不採用；不調整規則或判準。
- X2 未通過：開發資料上的改善沒有在新資料上重現。
- X3 未通過：實作與「無缺值時等於 v4」的設計不符，必須先找出原因，X2 的解讀暫停。
- R2：若不包住版本在新資料上不安全，支持包住的選擇；若安全，只表示包住在這份資料上可能過於保守，不據此修改 v5。
- 無論結果如何，不修改 v4、v5 或判準；改進屬於 v6，需要新資料。
