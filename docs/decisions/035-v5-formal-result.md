## 3. 只有 v4 對的集（事後、唯讀分析）

全部 7 個（8 個條件 × 3 個 budget 合計）都是 **absent 集：v4 判 absent、v5 判 inconclusive**；沒有任何一集變成 false absent 或 false present。

- 機制是路徑效應：v5 清除的位置是 v4 的超集。清除狀態不同時，rule-nbv-v2 對「剩下未清除位置」的增益預測也不同
  （以已觀測的障礙地圖估計，未知區域以固定機率計），因而選了不同的下一個視角。
- 例：`v5-g0036-v1`（D3×L1，budget 3）。第二個視角後 v4 清除 6.2%、v5 清除 51.6%；
  rule-nbv-v2 替 v5 選了視角 6，實際沒有清除新的位置（仍 51.6%）；v4 選到視角 7，一次清除 100%。
- 這是增益預測不準的已知限制（[failure analysis](../failure-analysis.md) §2、§4），不是 see-v5 的安全問題。
