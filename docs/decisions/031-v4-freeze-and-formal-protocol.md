# 031 — 凍結 v4，以及 v4 與 D3 的正式測試協定

- **日期**：2026-10-15
- **狀態**：凍結。本檔 commit 之後才產生正式資料（`v4`、`v4-dx`），正式評測只跑一次。
- **是否在看過正式結果後才寫**：否。v4 與 D3 都沒有任何正式結果；選擇只根據開發資料（decision 029、[docs/v4-development.md](../v4-development.md)）。

## 1. 凍結的 v4（`activeperception/v4/frozen_v4.py`）

只改位姿精修、其餘裕與 zone 過濾的定位不確定性；其餘與凍結的 v3（decision 025）相同：`detector-v1`、decision-v2 門檻、
zone 的範圍與寬裕（半徑 + 0.25 m）、see-through-v3、rule-nbv-v2、距離加權、5 m 截斷、最小特徵值 10、先驗閘門 3σ、
矛盾時不提供看穿、精修失敗時的寬餘裕 max(10 cm, 3σ)。

| 元件 | 凍結值 |
|---|---|
| 搜尋範圍 | 粗搜尋半寬 max(15 cm, 4σ)、max(0.08 rad, 4σ)，σ 為定位器回報的不確定度 |
| 比例假設 | 0.96、0.98、1.00、1.02、1.04，各自完整搜尋（粗階段用 500 點），最佳者再以 ±0.005 細化 |
| 尺度雅可比 | 開：不同比例的殘差以量測單位比較 |
| 成功時的餘裕 | 6 cm / 0.03 rad ＋ 成本在最佳 1.1 倍內的假設之位姿離散度 |
| 比例邊界規則、離散度過大時不提供看穿 | 關（開發資料上代價大於好處） |
| zone 過濾（`decision-v4`） | 偵測位置視為沿視線的一段（depth 比例 ±8%）：整段在 zone 內才能判 present；任何一點在 zone 內就擋下 absent |

開發依據（`v3-dev`，精修成功但誤差超出餘裕的視角）：D2×L2 65 → 11、D3×L1 144 → 5、D1×L1 21 → 4；
代價 absent@5 D2×L2 0.933 → 0.900、D3×L1 0.817 → 0.767、D1×L1 1.000 → 0.983。

zone 過濾：`v3-dev-dx` D3×L1 下，v3 與只改位姿的版本都把 1 集 absent 判成 present（zone 外 1.0 m 的消防栓，偵測框 depth 短了 6.3%）。
±8% 取自偵測框 depth 誤差的 99.5% 分位（D2 +4.4%、D3 −7.6%）。加入後該集為 0；沒有干擾物的場景結果不變；`v3-dev-dx` D0×P0 的 absent@5 1.000 → 0.983。

凍結設定在開發資料上（`v3-dev` D0×P0、D1×L1、D2×L2、D3×L1、D3×P0、D1×L2 回報 L1；`v3-dev-dx` D0×P0、D1×L1、D3×L1），
FA、FP、GR、全視角、佔用看穿全部是 0。

開發資料上也觀察到：凍結的 v3 在 `v3-dev-dx` D3×L1 有 false present（上述）。因此 D1（v3 在 D3 下安全）預期可能不通過。
D1 照原樣列為判準，不因此修改或移除。

參數來自真實相機量測，在任何 v3 / v4 結果之後都沒有調整。

## 5. 判準（事先寫定，不放寬）

「安全」＝ FA、FP、GR（策略所選視角）、全視角 GR、佔用位置看穿（0.06 m）全部為 0，與 decision 025 的 V1 相同。

| # | 判準 | 通過條件 |
|---|---|---|
| **W1（主要）** | v4、`v4` D1×L1 | 安全 |
| **W2（主要）** | v4、`v4` D1×L1 的 Rule budget 5 absent 正確率 | ≥ 0.90 |
| **W3（主要）** | v4、`v4` D2×L2（V4 失敗的條件） | 安全 |
| **W4（主要）** | v4、`v4` D3×L1 | 安全 |
| W5 | v4 的「精修成功但誤差超出餘裕」視角數，D2×L2 與 D3×L1 | 各自 ≤ 同資料上 v3 的 0.25 倍 |
| W6 | v4：`v4-dx` D1×L1 與 D3×L1、`v4` D3×P0、`v4` D1×L2 回報 L1 | 安全 |
| **D1（D3 正式驗證）** | 凍結的 v3：`v4` D3×L1、D3×P0、`v4-dx` D3×L1 | 安全 |

## 6. 解讀（事先寫定）

- W1–W4 通過：可以說「在模擬的典型、壓力與 D3 誤差下，v4 保持安全，並移除了 V4 失敗的機制」。仍然是**模擬**結論。
- W3 未通過：V4 型的失敗在新資料上仍出現；記錄機制，不調整。
- W5 未通過：開發資料上超出餘裕的大幅下降沒有在新資料上重現。
- D1 通過：凍結的 v3 在更接近真實相機的 D3 誤差下也安全。未通過：v3 的安全結論只在 D1 / D2 下成立。
- W2 或 absent 的代價（R1）：v4 以較大的餘裕換安全，absent 較難判。這是報告項目，不是調整的理由。
- 無論結果如何，不修改 v3、v4、D3 或判準；改進屬於 v5，需要新資料。
