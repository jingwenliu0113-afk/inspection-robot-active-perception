## 1. 使用者決定（2026-10-13）

採用「位姿精修 + 不確定性餘裕」（AskUserQuestion，建議選項），處理後再依標準進 B1。

## 2. 問題

`decision-v2` 以 depth 判定「看穿」（容忍值 0.03 m）。Core 用 teleport，相機位姿精確；Nav2 下只能用 AMCL 估計位姿，
B0 中位誤差 4.0 cm / 0.023 rad，幾何誤差與容忍值同量級 → 物件存在時仍可能被算成全部看穿（geometric false-absent risk）。

## 3. 設計（不改 `decision-v2` 的任何參數與規則）

### 3.1 位姿精修（`nav-pose-v1`，可部署）

輸入：AMCL 估計（初值）、機載 depth、已知桅桿外參、**先驗設施地圖的向量版本**——牆與柱子的 2D 矩形輪廓
（decision 015 的佔據地圖就是它的柵格化；**不含巡檢目標**，也不含 zone 禁入區）。

1. depth → 3D 點（每 4 個像素取 1、距離 ≤ 6 m）；以估計位姿轉到世界座標，只留高度 0.15–0.85 m 的點（低於所有柱子與牆的高度、高於地面），
   並丟掉落在 zone 中心 0.6 m 內的點（目標可能所在的區域）。
2. 對 (dx, dy, dyaw) 最小化「點到最近牆 / 柱子輪廓距離」的截斷平方誤差（截斷 0.10 m；未知物體與雜點自然成為離群）；
   搜尋範圍 ±0.15 m、±0.08 rad，先粗網格再細化。
3. **可觀測性**：以內點（距離 < 0.03 m）的輪廓法向量建立平移資訊矩陣與旋轉槓桿；最小特徵值低於門檻（例如只看到同一面牆 / 柱面）
   視為**退化**，不採用精修結果。

### 3.2 看穿判定的位姿不確定性餘裕（`nav-margin-v1`）

位置的「看穿比例」改為在一組位姿上取**最小值**：精修位姿 ± δxy（x、y 兩軸）× ± δyaw 的 27 個組合。
只有在所有組合下都被看穿，才算看穿（`decision-v2` 的 `col_min = 1`、`tau_clear = 1` 不變）。

- 精修成功：δ = 開發資料（`nav-b0`）上精修誤差 p95 的 2 倍，下限 0.01 m / 0.005 rad。
- 精修退化或失敗：退回 AMCL 估計，δ = 0.10 m / 0.06 rad（B0 的 AMCL 誤差 p95 再加餘裕）。

δ 與退化門檻只在 `nav-b0` 上決定（附錄 A），之後凍結。

## 5. GT 使用

精修與餘裕只用可部署輸入（AMCL 初值、機載 depth、向量設施地圖、桅桿外參）。真實位姿只用於評分（精修誤差、geometric risk）。
tests 檢查：精修函式的輸入不含 GT；地圖輪廓不含目標物件。
