## 3. 解讀（依 decision 027 §5 事先寫定）

- **T1 未通過**：不能說「困難負樣本微調把真實偏難負樣本的誤報壓到 A2 的標準以內」。
- 依「T1 未通過、但 v2 明顯降低誤報」的條款，報告實際降幅：
  - 確認負樣本的誤報從 8.4% 降到 4.7%，成對修好 43 張、弄壞 16 張，差異顯著。
  - absent 被擋的比例從 49.1% 降到 21.4%：在真實照片上，「沒有消防栓」的影像更常能被判為沒有。
- T2、T3 通過：召回沒有明顯退步，模擬中的 v3 管線仍然安全（T4）。
- **代價**：v2 的信心分佈比較「乾脆」，正樣本完全沒有反應（< 0.02）的影像從 4 張變成 10 張。
  在巡檢管線中，這類漏看還需要幾何也把消防栓的位置看穿，才會變成 false absent。
  模擬中 FA 為 0（T4），但這是一個在實機前要追蹤的風險，不能只看誤報下降。
- zone 內的相似物件（管件、閥門、柱狀設施）仍然是實機前的已知風險：4.7% 雖然較低，但不是 ≤ 1%。
- 不修改 `tau_present` / `tau_absent`；v1 / v3 的結果與凍結設定都不變。

## 4. 是否採用

decision 027 只規定「T2 或 T3 未通過 → 不採用」。v2 沒有觸發這一條，但 T1 是主要判準且未通過，因此：

- `detector-v2` **不取代** `detector-v1` 成為凍結的偵測器；v3 / v4 的正式測試繼續使用 `detector-v1`，才能把幾何與偵測的貢獻分開歸因。
- `detector-v2`（base）保留為「已驗證能降低真實誤報、但未達 A2」的候選，供實機前的決策參考。是否在實機管線中使用，是使用者的決定。

## 5. 範圍與限制

- test 只有 1 個資料來源類型的困難負樣本（人工確認、偏難），沒有相似物件類別；dev 顯示相似物件類別本來就很少被誤報。
- 單一訓練種子、單一架構；沒有做信心重新校準（那是另一個版本）。
- 真實照片是影像層級評估，不是巡檢視角，也不是實機。
