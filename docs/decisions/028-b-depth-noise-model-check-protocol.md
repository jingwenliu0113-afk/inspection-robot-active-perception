## 1. 問題

R0b、v3 的安全結論都建立在 `r0b_noise.py` 的 D1 / D2 模型上（decision 022 §3）。這個模型來自規格書，沒有對照過真實資料。B 問：

- **Q1**：D1 / D2 的每個參數，與真實 RealSense D435 / D455 的量測相比，是偏保守、相近，還是低估？
- **Q2**：有沒有模型完全沒有的誤差形式（例如單側遮蔽帶、粗量化、跨影像固定樣式）？
- **Q3**：若有低估或缺漏，v3 的安全性需要在什麼樣的修正模型下重新檢查？只寫建議與開發資料上的檢查，正式測試另寫 decision。

資料調查時的初步印象（6 張樣本，非正式）：

- D435 在 1–3 m 有約 −0.5% 到 −2.4% 的偏差（低估距離）；D455 在 2 m 約 +1.9%。
- 量化階距比 1 mm 粗很多。
- 相關長度可能比 3 px 長。

## 3. 量測（`activeperception/depthnoise/planes.py`；統計方法已在 R0b 模型上驗證能還原參數，`tests/test_depthnoise.py`）

每台相機、每個距離，都在平面中央 0.30 m × 0.30 m 的區域內量測：

| 量 | 定義 | 對應的模型參數 |
|---|---|---|
| bias | 中心深度中位數 / 雷射距離 − 1 | `bias`（D1 +1%、D2 +2%） |
| 空間 σ | 每張影像扣掉平面擬合後殘差的 robust σ，取各張中位數 | `rel_at_2m`（D1 1%、D2 2%）與 z² 成長 |
| 時間 σ、固定樣式 σ | 每個像素跨張數的 σ；各像素平均的平面擬合殘差 | 模型每個視角獨立抽樣，沒有固定樣式 |
| 缺值 | 平面區域內、整張影像內的缺值比例 | `dropout`（D1 1%、D2 3%） |
| 量化階距 | 區域內出現的最小深度差 | 模型為 1 mm |
| 相關長度 | 殘差自相關降到 1/e 的位移；先換成角度，再換成模擬相機的像素（640 px、60°） | `corr_px` 3（1/e 位移約 6 px） |

距離 σ 的成長以 σ(z) = a·z^p 擬合。

**平面資料量不到邊緣行為**（`edge_px`、flying pixel）。§5 以 Intel 規格的幾何公式估計，標明是推算、不是量測。

## 4. 比較準則（事先寫定）

D435 與 D455 分開判斷，只用 1–3 m 的距離（巡檢距離）：

| 參數 | 「模型保守或相近」的條件 | 否則 |
|---|---|---|
| 隨機誤差 | 量到的空間 σ ≤ D2 的 σ(z)；≤ D1 時記為「D1 已涵蓋」 | 「低估」 |
| bias | \|量到的 bias\| ≤ D2 的 2%。符號另外報告：模型只假設高估 | 「低估」；符號相反時記為「符號未涵蓋」 |
| 缺值 | 平面區域內缺值 ≤ D2 的 3% | 「低估」 |
| 量化 | 階距 ≤ 隨機誤差 σ 的一半（量化可忽略） | 「量化不可忽略」 |
| 相關長度 | 換算後 ≤ 模型的 2 倍（約 12 px） | 「相關更長」 |
| 固定樣式 | 固定樣式 σ ≤ 空間 σ 的一半 | 「固定樣式顯著」：多視角平均的效果可能被模型高估 |

## 5. 之後怎麼做（事先寫定）

- 每一項「低估」或「未涵蓋」，都寫成修正模型 D3 的一個參數。D3 的參數取兩台相機在 1–3 m 的最差值。
- 邊緣以 Intel 規格的遮蔽帶寬度推算：f·B·(1/z_前 − 1/z_後)，位於前景的單側。
- 在**開發資料**（`v3-dev`）上，用 D3 × L1 檢查凍結的 v3：FA、GR、全視角 GR、佔用看穿。
- D3 下的正式結論需要新的 decision、新的資料，並在看到開發結果之前先凍結 D3。
- 不修改 R0b、v3 已報告的任何結果，也不修改 D1 / D2 的定義；D3 是新的等級。
